# نظام الأفراد على أي حاسبة

انسخ **المجلد كاملاً** من الحاسبة التي يعمل عليها النظام، ثم انقر نقراً مزدوجاً على:

```bat
START.bat
```

لا تحتاج Python لفتح البرنامج، ولا قرص `H:`، ولا مساراً ثابتاً مثل `C:\Afrad2_work`.

## التشغيل

1. انسخ المجلد كاملاً (ليس ملف واحد): البرنامج `EXE` + `VFP*.DLL` + جداول `DBF/CDX`.
2. انقر `START.bat` أو `OPEN.bat`.
3. يفتح نظام الأفراد مباشرة.

المشغّل يفعل هذا بصمت:

- يكتب `config.fpw` بمسارات نسبية حتى لا ينكسر بعد النسخ
- يربط حرف `H:` بالمجلد إذا كان البرنامج القديم يبحث عن `H:\MFILE.DBF`
- يجهّز `C:\Afrad2_work` إذا كان المسار القديم مثبتاً داخل البرنامج
- ينشئ `MFILE.DBF` من `MFILE_updated.DBF` إن لزم
- **لا يفحص** الأقراص من `A:` إلى `Z:` حتى لا تظهر رسالة «أدخل قرصاً» من قارئ فارغ

## أدوات Excel (اختيارية)

Python مطلوب فقط لأدوات النقل والدمج، وليس لفتح النظام:

```bat
TOOLS.bat
```

| الرقم | الوظيفة |
|------:|---------|
| 1 | فتح نظام الأفراد |
| 2 | نقل بيانات Excel إلى `MFILE.DBF` |
| 3 | فحص الملفات فقط |
| 4 | دمج الأرقام حسب الاسم |
| 5 | تثبيت Python والمكتبات |
| 6 | تسريع الحاسوب (`GO.bat`) |
| 7 | نسخ `MFILE` إلى سطح المكتب |

أو مباشرة: `run_update_mfile.bat`

ضع ملف Excel و `MFILE.DBF` في هذا المجلد أو في `data`.

## لماذا كانت حاسبة تعمل وأخرى تظهر أخطاء؟

- البرنامج يبحث عن `H:\` بينما الجهاز بلا فلاش
- المسار `C:\Afrad2_work` غير موجود على الجهاز الجديد
- قارئ بطاقات أو DVD فارغ يظهر نافذة «أدخل قرصاً»
- ملف `.bat` عربي يتلف على ويندوز العربي
- مكتبات الفوكس `VFP*.DLL` غير منسوخة مع البرنامج
- `config.fpw` يشير إلى مسار الجهاز القديم

## ملاحظة عن البيئة السحابية

هذه البيئة لا تفتح برنامج الفوكس لويندوز. شغّل `START.bat` على الحاسبة نفسها بعد نسخ المجلد كاملاً.
