# نظام الأفراد على أي حاسبة

انسخ **المجلد كاملاً** من الحاسبة التي يعمل عليها النظام، ثم انقر نقراً مزدوجاً على:

```bat
START.bat
```

لا تحتاج قرص `H:` ولا مساراً ثابتاً مثل `C:\Afrad2_work`.  
المشغّل يبحث عن الملفات في المجلد الحالي و`data` وسطح المكتب والفلش، ويربط حرف `H:` بالمجلد إذا كان البرنامج القديم يعتمد عليه.

## لماذا تظهر أخطاء على حاسبة دون أخرى؟

غالباً لأحد هذه الأسباب، وقد عُولجت هنا:

- البرنامج يبحث عن `H:\MFILE.DBF` بينما هذا الجهاز بلا فلاش `H:`
- ملفات `.bat` العربية تتلف على ويندوز العربي وتظهر كأخطاء `powershell`
- Python غير مثبت أو غير موجود في PATH
- مكتبات FoxPro (`VFP9R.DLL` / `VFP6R.DLL`) غير منسوخة مع البرنامج
- `config.fpw` يشير إلى مسار الجهاز القديم

## أول تشغيل على جهاز جديد

1. انسخ مجلد المشروع كاملاً (ليس ملف EXE وحده).
2. ضع معه من الحاسبة التي يعمل عليها:
   - برنامج الأفراد `*.EXE`
   - مكتبات الفوكس `VFP*.DLL` و`MSVCR71.DLL` إن وُجدت
   - جداول `*.DBF` و`*.CDX` و`*.FPT`
3. انقر `START.bat` (أو `OPEN.bat`).
4. إذا طلب Python: اسمح لـ `install_python.bat` ثم أعد `START.bat`.

## القائمة بعد التشغيل

| الرقم | الوظيفة |
|------:|---------|
| 1 | فتح نظام الأفراد |
| 2 | نقل Excel إلى `MFILE.DBF` |
| 3 | فحص الملفات فقط |
| 4 | دمج الأرقام حسب الاسم |
| 5 | تثبيت Python والمكتبات |
| 6 | تسريع الحاسوب (`GO.bat`) |
| 7 | نسخ `MFILE` إلى سطح المكتب |

## نقل Excel إلى MFILE.DBF

ضع الملفين في هذا المجلد أو في `data` (لا يشترط `H:`):

- ملف Excel
- `MFILE.DBF`

ثم من القائمة اختر 2، أو انقر `run_update_mfile.bat`.

الأداة تحافظ على ترميز الفوكس القديم (`cp1256`) وLanguage Driver.

```bat
python update_mfile_from_excel.py --inspect-only
python update_mfile_from_excel.py --dry-run
python update_mfile_from_excel.py
```

## تسريع الحاسوب

```bat
GO.bat
```

ملف ASCII يعمل على ويندوز العربي دون رسائل ترميز تالفة. الدليل: [`SPEED_UP_PC.md`](SPEED_UP_PC.md)

## ملاحظة عن البيئة السحابية

هذه البيئة لا تفتح برنامج الفوكس لويندوز. شغّل `START.bat` على الحاسبة نفسها بعد نسخ المجلد كاملاً.
